# ayu — Skeb Reference Page

GitHub Pages 用の静的サイトです。

## 公開方法
1. このフォルダの中身（`index.html` と `images` フォルダ）をGitHubのPublic repositoryにアップロード。
2. Repository → Settings → Pages。
3. Sourceを「Deploy from a branch」にする。
4. Branchを `main`、フォルダを `/ (root)` にしてSave。
5. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開できます。
